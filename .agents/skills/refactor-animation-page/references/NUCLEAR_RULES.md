## ⚡ 一、controlsMode 决策铁律

近代物理与核物理包含“稳态微观结构”与“随机统计过程”两大范畴，**严禁机械套用力学默认的 `timed` 模式**：

| 核物理场景类型 | 适用模式 | 决策理由与典型案例 |
|---------------|---------|-------------------|
| **结合能、质能方程与质量亏损天平** | `controlsMode: 'param'` | 属于稳态静态对比：用户切换核种、增减 $\Delta m$ 砝码观察天平平衡与比结合能曲线，无需倒计时播放条 |
| **原子核的组成与同位素结构** | `controlsMode: 'param'` | 调节核子间距 $r$ 探索强核力短程引斥力平衡，纯参数稳态交互 |
| **四大核反应方程配平与分类辨析** | `controlsMode: 'param'` | 交互式选择反应物与生成物配平，静态推导与分类判定 |
| **玻尔原子模型与能级跃迁光子辐射** | `controlsMode: 'param'` | 选择初末能级 $n$ 激发或辐射光子，静态跃迁台阶图 |
| **放射性元素半衰期统计演化** | `controlsMode: 'timed'` | 大量原子核随时间随机衰变演化，需结合时间轴呈现衰变曲线与剩余核数 |
| **静止母核衰变与磁场内切/外切圆径迹** | `controlsMode: 'timed'` | 粒子瞬间反冲飞出并画圆周运动的过程，动态演示洛伦兹力偏转 |
| **重核单次裂变与铀核链式反应** | `controlsMode: 'timed'` | 中子撞击裂变并释放 2~3 个快中子的增殖过程，有时序扩散 |

> ❌ **严禁违规**：禁止在稳态结构（天平质量亏损、核子组成、反应方程式配平）页面配置 `controlsMode: 'timed'`！这会在底部产生毫无物理意义的 10 秒倒计时进度条。

## ⚡ 二、跨 15 个数量级尺度与视景坐标映射铁律

在真实微观物理中，核物理具有极度极端的跨尺度特征：
- 原子核与核子尺度：$d \sim 10^{-15}\text{ m}$ (1 fm)
- 磁场中带电微粒轨道半径：$R \sim 10^{-2}\text{ m}$ (数厘米)
- 粒子能量与结合能：$\text{MeV}$（$1\text{ u} = 931.5\text{ MeV}$）
- 衰变半衰期时间尺度：从微秒到数十亿年（$^{238}\text{U}$ 达 44.7 亿年，$T_{1/2}$ 跨度极大）

**若按真实米数设置 SceneScale，浮点精度崩溃、微观核子尺寸将缩为 0。**

### ✅ 规范架构：双层映射机制
1. **物理计算层（Hook / quantities）**：
   - 必须采用严格的物理标准单位：质量用 $\text{u}$，能量用 $\text{MeV}$，间距用 $\text{fm}$，宏观磁场用 $\text{T}$ 与 $\text{cm}$；
   - 输出真实物理量：质量亏损 $\Delta m$（$\text{u}$）、结合能 $E_b$（$\text{MeV}$）、比结合能 $E_{\text{avg}}$（$\text{MeV/nucleon}$）、半径比 $R_1 : R_2$、动能分配比 $E_{k1} : E_{k2}$；
   - 确保右屏 `PhysicsPanel` 看板中显示的数值 100% 真实准确。
2. **视景呈现层（Scene / Layout）**：
   - **微观核子排布**：核子球体（质子/中子）在设计坐标系下采用示意尺度（直径 20~28px）；
   - **宏观轨道缩放**：磁场中的外切圆与内切圆，按真实物理推导的电荷反比 $R \propto 1/|q|$ 在设计坐标系内等比缩放渲染；
   - ❌ **严禁虚假参数**：严禁在 `useSceneScale` 中直接填入 `physicsWidth: 1e-14` 或随意凑数。必须采用设计中心对齐或示意比例尺。

## ⚡ 三、微观粒子色彩与视觉标准

微观物理严禁使用力学金属反光材质（禁止使用 `<Ball type="steel">` 代表核子），严格使用统一语义色彩：

| 粒子 / 元素 | 语义色彩 Token | 视觉规范 |
|------------|---------------|---------|
| **质子 (p, $^1_1\text{H}$)** | `PHYSICS_COLORS.forceArrowRed` (`#B91C1C`) | 正电红球，带白色“+”标识 |
| **中子 (n, $^1_0\text{n}$)** | `PHYSICS_COLORS.appliedForce` (`#1E3A8A`) | 中性蓝球，无符号，比质子略重 |
| **电子 / $\beta$ 粒子 ($^0_{-1}\text{e}$)** | `PHYSICS_COLORS.velocity` (`#2563EB`) | 极小高速青蓝光点，带“-”标识，带发光尾迹 |
| **$\alpha$ 粒子 ($^4_2\text{He}$)** | `PHYSICS_COLORS.photonInfrared` (`#B91C1C`) | 双质子+双中子紧密结合的紧凑四核团 |
| **$\gamma$ 光子 / 高能辐射** | `PHYSICS_COLORS.wavelength` (`#D97706`) | 金黄色正弦波动光束或高能脉冲光斑 |
| **母核 / 反冲新核** | `PHYSICS_COLORS.potentialEnergy` (`#7C3AED`) | 大质量深紫/深色复合核球团 |
| **核力短程引力连线** | `CANVAS_COLORS.referencePoint` (金黄半透明) | 仅在 $r < 1.1\text{ fm}$ 时显现金光键连 |

## ⚡ 五、高考三大压轴模型交付标准

### 1. 静止母核磁场衰变模型（内切圆 vs 外切圆）
- **动量守恒**：$0 = \vec{p}_1 + \vec{p}_2 \implies p_1 = p_2 = p$
- **轨道半径反比于电荷**：$R = \frac{p}{|q|B} \implies \frac{R_1}{R_2} = \frac{|q_2|}{|q_1|}$
- **几何切向判定**：
  - $\alpha$ 衰变：两粒子均带正电，初速度相反，向切线相反侧偏转 $\implies$ **外切圆**；
  - $\beta$ 衰变：一正一负，初速度相反，向切线同侧偏转 $\implies$ **内切圆**；
- **动能反比分配**：$E_k = \frac{p^2}{2m} \implies \frac{E_{k1}}{E_{k2}} = \frac{m_2}{m_1}$（轻微粒分得绝大部分动能）。

### 2. 爱因斯坦质能方程与质量亏损天平模型
- **概念隔离**：明确区分“结合能”与“比结合能（平均结合能）”。结合能大不等于稳定（$^{238}\text{U}$ 结合能远大于 $^{56}\text{Fe}$，但铁的比结合能达 8.8 MeV 为全周期顶点最稳定）；
- **天平交互**：左盘为自由分散核子总质量 $Z m_p + N m_n$，右盘为原子核质量 $M_X$。天平左沉右翘；右盘补上 $\Delta m$ 砝码后完美恢复水平。

### 3. 半衰期统计规律与碳-14 考古测年模型
- **统计本质**：蒙特卡洛随机离散衰变点 + 理论光滑指数曲线双层叠加展示，彰显“宏观大量统计成立、微观单个无意义”；
- **外因无关性**：调节环境温度与压强，衰变曲线完全恒定；
- **C-14 考古断代**：提供残留比例计算功能（如 $12.5\% = (1/2)^3 \implies t = 3T = 17190\text{ 年}$）。

### 4. 重核裂变链式反应与核反应堆模型
- **链式条件**：慢中子诱发裂变，释放 2~3 个快中子；必须达到**临界体积**；
- **反应堆控制核心构件**：
  - 减速剂（重水/石墨）：使快中子碰撞减速为热中子；
  - 控制棒（镉棒/硼棒）：吸收中子，通过升降插入深度实时调控链式增殖速率。
