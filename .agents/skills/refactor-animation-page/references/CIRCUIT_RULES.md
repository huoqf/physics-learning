# 电学实验与电路原理图规范 (CIRCUIT_RULES)

> 本文件供重构或开发所有涉及**直流电路、电学实验（测电阻率、测电动势与内阻、小灯泡伏安特性、电表改装、多用电表、传感器电路、交流电等）**页面时作为通用标准执行。
> 严禁针对个别页面硬编码特例，所有电路图必须遵循高中物理教科书标准画法与统一组件规约。

---

## 1. 高中物理教科书电路标准画法（核心铁律）

### 1.1 矩形回路骨架与器件合理布局
- **横平竖直标准矩形回路**：
  任何电路图主回路必须以清晰的矩形框架布线，导线横平竖直，拐角为 90° 直角（或微圆角）。严禁斜向飞线，严禁导线与元器件几何体交叉重叠。
- **功能分区明晰**：
  - **主供电干路**（通常置于底横线或左侧垂直线）：放置直流电源与主电键 S；
  - **控制调节支路**：放置滑动变阻器、电阻箱或分压电位器；
  - **测量工作区**（通常置于顶横线或右侧区域）：放置待测负载与测量电表（A / V / G）；
  - **测量仪器工位独立**：机械测量（刻度尺、游标卡尺、螺旋测微器）必须与电路原理图在空间上严格解耦，不得将刻度尺伪造成电路中的一根导线。
- **空间安全边距（零重叠红线）**：
  - 区域标题、接法徽章与元器件必须留有充足水平或垂直间距，严禁任何标题压盖接线柱或元件；
  - 电表表盘正负极标志（`+`、`-`）与示数文本必须与表盘圆形外壁保持 6~15px 安全间距，严禁两层文本在同坐标叠打。

### 1.2 高中物理电学严谨性
- **电流是标量**：导线上严禁出现力/速度矢量箭头（`PhysicsVectorArrow`），严禁画带箭头的流动电荷伪动画。
- **红进黑出原则（极性统一）**：
  - 回路电流由电源正极经外电路流向负极；
  - 电流必须由电流表、电压表的**正接线柱（红表笔，标 `+`）流入**，由**负接线柱（黑表笔，标 `-`）流出**；
  - 待测负载两端的高电势端接电表正接线柱，低电势端接负接线柱。
- **外接法与内接法标准拓扑**：
  - **外接法**（测小电阻，消除电压表分流影响）：
    电压表仅跨接在待测负载两端，电流表串联在测量区外部干路上；
  - **内接法**（测大电阻，消除电流表分压影响）：
    电流表与待测负载直接紧密串联，电压表跨接在“电流表 + 待测负载”串联总段的两外侧节点之间；
- **真实拓扑连接（零伪连线，零假遮罩）**：
  - 严禁“一条通线穿到底 + 元件背后垫白色假矩形遮挡”；
  - 导线必须基于端子到端子（Terminal-to-Terminal）分段连线；
  - 任何 T 型并联分流或汇流节点，必须绘制实心圆点（`r = 3.5`，`fill={CIRCUIT_COLORS.node}`）。

## 2. 核心电学与测量组件调用规约（统一标准，严禁私下手写）

所有电学电路页面必须复用 `@/components/Physics`，禁止手写等效 SVG。

| 组件名 | 标准参数调用规约 | 核心注意事项 |
|---|---|---|
| **`DCSource`** | `type="symbol"`<br>`polarity="right-positive"`（长正极在上）<br>`voltage={E}` | 统一调用导出的 `getDCSourceTerminals(x, y, polarity)` 获取精确端子（或常量 `DC_SOURCE_SYMBOL_OFFSET`），与竖直干线无缝对接，禁止硬编码魔数。严禁将垂直符号直接插入水平走线。 |
| **`DialMeter`** | `type="V" \| "A" \| "G"`<br>`variant="symbolic"`<br>`showLabel={false}`（推荐外层唯一定义示数）<br>`r={28 ~ 34}` | 表头为标准空心圆圈加英文字母；传 `showLabel={false}` 可避免组件内置示数与外层自定义示数在同坐标重叠；表盘两侧明确标注红正黑负。 |
| **`Rheostat`** | `variant="symbolic"`<br>`value={R}`<br>`width={110 ~ 130}` | 限流式必须“一上一下”接入（滑杆端与电阻端水平引出）；分压式两下端跨接全压，滑杆端输出。滑片位置必须与阻值参数真实机械联动。 |
| **`CircuitSwitch`**| `variant="symbolic"`<br>`closed={boolean}`<br>`label="S"` | 水平引出端为 `(x - 18, y)` 与 `(x + 18, y)`，外部导线平直接入端子。 |
| **`LabRuler`** | `domain={[start, end]}`<br>`styleType="steel" \| "wood"`<br>`length={px}` | 严禁通过 map 循环手写刻度线与数字；用于长度读数时金属丝贴合刻度边缘。 |
| **`Micrometer`** | `measuredValue={d_mm}`<br>`showMagnifier={true}` | 直径测量标准器材，附带固定刻度、半刻度与可动微分筒放大特写。 |

## 3. 页面重构自检 Checklist（提交前必过）

- [ ] 电路图元器件（电源、开关、变阻器、电表）全部复用 `@/components/Physics` 标准组件，无私下手绘符号；
- [ ] 原理图统一使用 `variant="symbolic"`；
- [ ] 电表无两层示数重叠，正负极（红正黑负）符合顺时针电流走向；
- [ ] 导线横平竖直，无倾斜飞线，端子严格接合，T 型节点带实心圆点；
- [ ] 机械测量组件（刻度尺/卡尺/千分尺）独立于电路原理图，不混淆物理角色；
- [ ] 区域标题、接法徽章与元器件无任何空间碰撞和文本压盖。
