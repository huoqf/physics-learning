# THERMAL_RULES.md — 热学微观与宏观实验定律工程规范

> 本文件是热学领域（分子动理论、气体实验定律、热力学定律）的权威工程与教学规范。
> 涉及热学微观与宏观场景新建与重构时必须严格遵守。

## ⚡ 一、controlsMode 决策铁律

热学场景具有强烈的微观统计与宏观状态演化特性，**严禁机械套用力学默认的 `timed` 模式**：

| 热学场景类型 | 适用模式 | 决策理由与典型案例 |
|-------------|---------|-------------------|
| **分子热运动 / 布朗运动 / 气体分子碰撞** | `controlsMode: 'loop'` | 微观热运动“永不停息”，无固定起终点；设定为 `timed` 会导致 10 秒后荒谬静止 |
| **状态参量探究（玻意耳/查理/盖-吕萨克/克拉珀龙）** | `controlsMode: 'param'` | 由学生拖动 $V$ 或 $T$ 滑块探索平衡态，无需自动时间流逝 |
| **分子力-势能随距离变化 / 理想气体微观估算** | `controlsMode: 'param'` | 纯参数探索与曲线对应，无时间流逝驱动 |
| **油膜法实验操作步骤（分阶段呈现）** | `controlsMode: 'param'` | 通过分步分段器 (Step) 切换实验流程，参数与阶段展示 |
| **闭合热力学循环（卡诺/斯特林等正向热机）** | `controlsMode: 'timed'` | 状态点在 $p-V$ 封闭回路连续演化并对外做功 |

> **注**：对于混合模式页面（如热力学第一定律沙箱与循环双模式），controlsMode 优先服务于需要时间推进的核心模式（如 timed 热机循环），沙箱子模式下保持参数响应。

## ⚡ 二、宏观气体实验与活塞汽缸受力规范（教学核心铁律）

在高中物理与新高考中，活塞汽缸是热学大题的核心载体，**受力分析必须 100% 物理保真**：

1. **压强受力矢量方向铁律（严禁颠倒）**：
   - 气缸内封闭气体压强对活塞底面的作用力方向**必须垂直向上顶活塞**（$F_{\text{内}} = pS \uparrow$），严禁从活塞顶端向下绘制内部气体压力！
   - 活塞上表面受力：必须明确标注外界大气压力（$F_0 = p_0 S \downarrow$）和活塞/砝码自身重力（$G = mg \downarrow$），形成直观清晰的受力平衡对立（$pS = p_0 S + mg$）。
2. **状态变化约束机构显式呈现**：
   - **等压过程（盖-吕萨克定律）**：活塞上方必须显式绘制金属配重砝码或标明恒定外力，解释为什么压强恒定；
   - **等容过程（查理定律）**：汽缸内壁必须显式绘制机械卡槽或锁止销钉（Lock Pins），解释为什么体积保持不变；
   - **等温过程（玻意耳定律）**：必须显式标明“恒温水浴/恒温环境”以及缓慢推拉活塞操作。
3. **真实实验仪器视角**：
   - 探究气体等温变化实验必须还原高中教材标准实验仪器：带刻度注射器筒 + 橡胶软管 + 数字气压计/压力表。

## ⚡ 三、微观多粒子系综渲染性能铁律

1. **严禁在粒子系综中滥用宏观质点 `<Ball>`**：
   - `<Ball>` 组件内含复杂的 SVG `<radialGradient>`、光泽滤镜与投影，适合力学 1~3 个宏观球体。
   - 热学微观碰撞或气体模拟往往需要渲染 30~200 个分子。大量实例化 `<Ball>` 会引发严重的 DOM 树膨胀和重绘卡顿。
2. **轻量化渲染规范**：
   - 批量分子渲染必须使用单色扁平原生 `<circle>` 或池化渲染。
   - 统一使用 `PHYSICS_COLORS` / `THERMO_COLORS` 语义色。
   - 只有受重点追踪的特定大颗粒（如布朗运动中的花粉微粒）才允许使用 `<Ball>`。

## ⚡ 四、坐标尺度与 SceneScale 映射规范

1. **微观极小量与浮点精度保护**：
   - 单个分子尺寸约为 $10^{-10}\text{ m}$，若直接将 $10^{-10}$ 作为 `physicsWidth` 传入 `useSceneScale`，浮点运算将出现精度丢失或除零异常。
2. **宏观与微观映射标准**：
   - **分子间距曲线（$F-r, E_p-r$）**：必须使用**无量纲归一化坐标**，横坐标以平衡距离 $r_0$ 为单位（$r \in [0.5 r_0, 4.0 r_0]$，在 $r \ge 4.0 r_0$ 处相互作用力已衰减至不足峰值 1%）。
   - **宏观几何容器（汽缸/玻璃管）**：采用标准设计坐标系映射，物理看板中严格转换为宏观国际单位（$\text{Pa}, \text{kPa}, \text{m}^3, \text{L}, \text{K}$）。

## ⚡ 五、三屏与热学图表规范

1. **Preset 选型**：
   - **立式汽缸 + 单状态图**：使用 `CANVAS_PRESETS.splitH`；
   - **卧式汽缸 / 连通汽缸 / 双图联动（$p-V$ 与 $V-T$ 对照，或 $p-V$ 配合功与热条形图）**：必须使用 `CANVAS_PRESETS.splitV`。
2. **热学高考核心图表支持**：
   - **三大状态图**：$p-V$ 图（等温双曲线）、$p-T$ 图（过绝对零度直线）、$V-T$ 图（过绝对零度直线）；
   - **外推虚线规范**：$p-T$ 与 $V-T$ 图线反向外推必须使用虚线延伸至绝对零度（$-273.15^\circ\text{C}$ 或 $0\text{ K}$）；
   - **等温线族**：进阶模式需展示不同温度下的等温线族，明确 $T_1 < T_2 < T_3$ 离原点越远温度越高；
   - **麦克斯韦速率分布**：支持不同温度（$T_1 < T_2$）双曲线对照，标明最概然速率 $v_p$、平均速率 $\bar{v}$，体现“中间多、两头少、面积守恒”。

## ⚡ 六、热学高考核心实验规范（油膜法与等温变化实验）

1. **油膜法实验**：
   - 必须包含：溶液稀释配制、单滴体积标定、痱子粉水面撒布、单分子油膜扩散、坐标方格纸计数。
   - 分子直径计算严格满足 $d = \frac{V}{S} \approx 10^{-10}\text{ m}$；计数规则遵循高考标准（大于半格算一格，小于半格舍去）。
2. **探究气体等温变化实验（玻意耳定律）**：
   - 图象必须支持 $p-V$（反比曲线）与 $p-\frac{1}{V}$（过原点直线）切换验证；
   - 必须在看板或提示中说明误差成因：软管死体积使图线不过原点、快速推拉漏气或温度变化使图线弯曲。

## ⚡ 七、热力学定律与热机循环规范（热学第 3 章专项）

1. **热机循环顺时针铁律（严禁颠倒）**：
   - 在 $p-V$ 坐标系中，**正向热机循环路径必须严格为顺时针方向**（等容加热升压 $\to$ 高压等压膨胀对外做功 $\to$ 等容放热降压 $\to$ 低温低压等压压缩回程）；
   - **做功与效率物理保真**：高压膨胀对外做功大于低压压缩外界输入的功，全循环对外输出净正功严格等于 $p-V$ 闭合图形面积；逆时针为耗功制冷机循环，严禁颠倒混淆。
2. **热力学第一定律符号体系与受力真实感**：
   - 严格遵守第一定律统一符号体系（$\Delta U = W + Q$），明确 $W$ 为外界对气体做的功；看板必须明确提醒学生：题干给出“气体克服外界做功”时需取负号；
   - 活塞底面受缸内气体压强作用力垂直向上顶活塞（$F_{\text{内}} = pS \uparrow$），活塞顶面受外界压力向下（$F_{\text{外}} \downarrow$）；
   - 严禁将“绝热”与“等温”混淆，绝热压缩必定导致温度升高。
3. **热力学第二定律三屏与教学辩证规范**：
   - **主屏文字约束**：SVG 主屏仅保留物理矢量箭头与区域物理量标注，严禁在画布内部硬编码“演示一”、“已达平衡”等大段教学标题或状态长文本（统一归拢至右屏看板与左屏控制台）；
   - **辩证对照**：必须向学生阐明克劳修斯表述与开尔文表述的“自发”限定——有外界做功或消耗电能介入时（如电冰箱、空调制冷），热量完全可以从低温传向高温。
