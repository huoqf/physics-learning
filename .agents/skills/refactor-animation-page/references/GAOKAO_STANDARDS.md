# 高考教学法与计量规范 (GAOKAO_STANDARDS)

> 本文件供重构或开发涉及**物理量展示、右屏看板、图表游标、单位符号**时按需读取。

---

## 1. 课标单位与量纲一致性

- **严禁使用高中课标外单位**：
  - 频率：高中物理仅使用 $\text{Hz}$、$\text{kHz}$、$\text{MHz}$、$\text{GHz}$；严禁在高中动画看板中使用 $\text{THz}$，红外/可见光/紫外统一使用波长（$\text{nm}$、$\mu\text{m}$）或标准科学记数法（$\times 10^{14}\text{ Hz}$）。
  - 波长：优先使用米制标准前缀（$\text{km}$、$\text{m}$、$\text{cm}$、$\text{mm}$、$\mu\text{m}$、$\text{nm}$、$\text{pm}$）。
- **微观尺度参照物对应**：
  卡片与图表中的宏微观尺度参照物必须严谨对应波长数量级：
  - $\sim 100\text{ m}$：高楼大厦
  - $\sim 1\text{ cm}$：硬币 / 昆虫
  - $\sim 10\ \mu\text{m}$：针尖大小
  - $\sim 0.5\ \mu\text{m}$：细菌 / 细胞
  - $\sim 200\text{ nm}$：大分子 / 病毒
  - $\sim 1\text{ nm}$：纳米尺度 / DNA 双螺旋直径 / 蛋白质分子
  - $\sim 0.1\text{ nm}$：单个原子直径
  - $\sim 1\text{ pm}$：原子核级

## 2. 数值格式化与防科学记数法泄漏

- **禁止裸科学记数法**：
  严禁向学生呈现 `1.00e+3`、`3.17e-7` 等编程语言裸记法；必须使用带 Unicode 上标的标准形式（如 `3.00 × 10⁸ m/s`）。
- **极小浮点残差零截断**：
  - 振荡零点或极值点处，浮点误差会导致计算出 `−6e-17` 或 `1.87e-33`。
  - 在 format 处理前必须做零截断保护（如 `Math.abs(val) < 1e-4 ? 0 : val`），严禁游标出现 `-0.00` 或右屏出现 `3.17e-7 J`。
- **小数位数平滑，拒绝跳变**：
  同一物理量在不同数值区间应保证平滑过渡，严禁真零显示 `0.00`、极小微量显示 `0.0000` 造成的跳变不适感。
- **999.5 升档临界点**：
  涉及带单位前缀的升档函数（如 `formatFrequency`、`formatWavelength`），必须在 `999.5` 进行升档（如 `999.6 kHz → 1.00 MHz`），杜绝因四舍五入出现 `1000.0 kHz` 的尴尬数值。

## 3. 高中物理课标边界与公式分级铁律

> 本节由 `scripts/check-curriculum-standards.mjs`（`npm run check:curriculum`）在 CI 中自动把关。

- **4 档 `Formula.level` 的课标语义**：
  - `core`：现行人教版高中教材要求掌握的**核心主干公式**（可直接用于定量求解与高考解答）。
  - `important`：教材重点推论、常见实验规律或重要二级关系。
  - `derived`：由主干公式消元/联立得到的推导中间式。
  - `supplementary`：**课外拓展/定性演示式**（如大学解析解、微积分形式），高中**不要求推导或记忆**。
- **高数符号分级红线**：
  凡 `latex` 中包含微积分或高数解析符号（`\int`、`\oint`、`\partial`、`\nabla`、微分商 `\frac{d...}{dt}` 或指数暂态解 `e^{-...}`）的公式，**严禁标为 `core` 或 `important`**；必须优先改写为高中标准表达式（如 $\Delta S/\Delta t = \text{常数}$、$\sum F\Delta t$、$|e_L| = L|\Delta i/\Delta t|$），若保留拓展形式则必须标 `level: 'supplementary'` 或 `'derived'`，并在 `condition`/`note` 中注明高中仅作定性理解或用图像面积/守恒定律求解。
- **大学术语与过时口径禁令**：
  - 严禁在看板与注册表文案中出现高数/大学物理黑话：`泰勒`、`微积分`、`微分方程`、`偏导`、`二阶导`、`拉格朗日`、`哈密顿`、`旋度`、`散度`、`张量`、`薛定谔`、`傅里叶`、`拉普拉斯`、`本征`、`算符`。
  - 狭义相对论统一采用现代物理**不变质量 $m_0$** 口径（$E = \gamma m_0 c^2$），禁止使用旧版“相对论质量 / 质速关系”引导质速综合计算。

## 5. 高中物理 10 大概念与表述红线表

> 下列物理概念与表述由 `scripts/check-curriculum-standards.mjs`（`CONCEPT_REDLINE_RE`）协同把关：

1. **力学因果与惯性**：力是改变物体运动状态的原因（非维持原因）；惯性只由质量决定，与速度大小无关。
2. **惯性系受力口径**：惯性系分析严禁把假想“惯性力”“离心力”当作性质力；物体做离心运动是因为合外力不足以提供所需向心力；轻杆过最高点临界速度为 $v \ge 0$。
3. **教材物理量正名**：统一称**磁感应强度 $B$**（严禁写“磁场强度 $B$”）、**动摩擦因数 $\mu$**（静摩擦极大值 $f_{\max} = \mu_s F_N$ 不泛化为 $\mu mg$）、**引力常量 $G$**、**静电力常量 $k$**、**普朗克常量 $h$**、**偶数/偶然误差**（不写“偶发误差”）。
4. **静电与屏蔽口径**：正电荷周围“近大远小”，负电荷周围“近小远大”；三点电荷平衡“两同夹异、两大夹小、**近小远大**”；静电屏蔽外电场需将**金属壳接地**（非“壳内带电体接地”）；沿电场线方向电势降低，与场强大小无关。
5. **直流电路口径**：非线性元件电阻定义式 $R = U/I$ 随温度/电压变化，严禁写“非线性反比”；“串反并同”须电源内阻及干路总电阻非零；$P_{\text{外}\max}$ 对应 $R = r$ 须外电路为纯电阻且变阻器阻值范围包含 $r$；电动机非纯电阻满足 $U_M I = I^2 r_M + P_{\text{机}}$。
6. **动量、能量与运动学**：完全非弹性碰撞**机械能损失最大（产生内能最多）**（严禁写“内能损失最大”）；单向匀变速直线运动恒有 $v_{s/2} > v_{t/2}$；平抛逐差式为二次差 $\Delta(\Delta y) = gT^2$；弹跳平均撞击力统计全接触过程时间 $2\Delta t$。
7. **机械振动与波、几何光学**：单摆简谐条件须写明小角度 **$\theta_0 < 5^\circ$**；微波炉利用极性水分子在高频交变电场中急剧转向生热，**不属于机械共振实例**；折射率 $n = \sin\theta_1/\sin\theta_2$ 须标明真空/空气射入介质；凹透镜恒成正立缩小虚像，不可混用凸透镜结论。
8. **波动光学与电磁波**：双缝测条纹间距多条取平均为**累积法**（非“逐差法”）；激光截面照射表征物理量为**功率密度 $I = P/S$**（单位 $\text{W/m}^2$，非“能量密度”）；相变潜热须乘质量 $mL_f + mL_v$；电磁波谱穿透/电离能力按波长频率单调律严格区分无线电波与 X/$\gamma$ 射线。
9. **热学与分子动理论**：气体实验三定律与 $pV/T = C$ 仅限**一定质量的理想气体**且 $T$ 为热力学温度 $\text{K}$；热力学第二定律 $\Delta S \ge 0$ 须限定**孤立系统**；绝热指数 $\gamma \approx 1.67$ 仅限单原子理想气体；单晶体表现为“在某些物理性质上各向异性”。
10. **近代物理口径**：玻尔理论光子吸收跃迁须满足 $h\nu = E_m - E_n$ 或 $h\nu \ge |E_n|$（电离）；核反应质能亏损 $\Delta E = \Delta m c^2$，质量数关系 $A = Z + N$ 为核子数关系而非质量守恒；卢瑟福与汤姆孙散射模型不可混用同一最近距离计算。
