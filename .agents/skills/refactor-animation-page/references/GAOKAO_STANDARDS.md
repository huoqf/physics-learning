# 高考教学法与计量规范 (GAOKAO_STANDARDS)

> 本文件供重构或开发涉及**物理量展示、右屏看板、图表游标、单位符号**时按需读取。

---

## 1. 课标单位与量纲一致性

- **严禁使用高中课标外单位**：
  - 频率：高中物理仅使用 $\text{Hz}$、$\text{kHz}$、$\text{MHz}$、$\text{GHz}$；严禁在高中动画看板中使用 $\text{THz}$，红外/可见光/紫外统一使用波长（$\text{nm}$、$\mu\text{m}$）或标准科学记数法（$\times 10^{14}\text{ Hz}$）。
  - 波长：优先使用米制标准前缀（$\text{km}$、$\text{m}$、$\text{cm}$、$\text{mm}$、$\mu\text{m}$、$\text{nm}$、$\text{pm}$）。
- **微观尺度参照物对应**：
  卡片与图表中的宏微观尺度参照物必须严谨对应波长数量级：
  - $\sim 100\text{ m}$：高楼大厦
  - $\sim 1\text{ cm}$：硬币 / 昆虫
  - $\sim 10\ \mu\text{m}$：针尖大小
  - $\sim 0.5\ \mu\text{m}$：细菌 / 细胞
  - $\sim 200\text{ nm}$：大分子 / 病毒
  - $\sim 1\text{ nm}$：纳米尺度 / DNA 双螺旋直径 / 蛋白质分子
  - $\sim 0.1\text{ nm}$：单个原子直径
  - $\sim 1\text{ pm}$：原子核级

## 2. 数值格式化与防科学记数法泄漏

- **禁止裸科学记数法**：
  严禁向学生呈现 `1.00e+3`、`3.17e-7` 等编程语言裸记法；必须使用带 Unicode 上标的标准形式（如 `3.00 × 10⁸ m/s`）。
- **极小浮点残差零截断**：
  - 振荡零点或极值点处，浮点误差会导致计算出 `−6e-17` 或 `1.87e-33`。
  - 在 format 处理前必须做零截断保护（如 `Math.abs(val) < 1e-4 ? 0 : val`），严禁游标出现 `-0.00` 或右屏出现 `3.17e-7 J`。
- **小数位数平滑，拒绝跳变**：
  同一物理量在不同数值区间应保证平滑过渡，严禁真零显示 `0.00`、极小微量显示 `0.0000` 造成的跳变不适感。
- **999.5 升档临界点**：
  涉及带单位前缀的升档函数（如 `formatFrequency`、`formatWavelength`），必须在 `999.5` 进行升档（如 `999.6 kHz → 1.00 MHz`），杜绝因四舍五入出现 `1000.0 kHz` 的尴尬数值。
