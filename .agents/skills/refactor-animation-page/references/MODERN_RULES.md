## ⚡ 一、controlsMode 决策铁律

近代物理以“量子微观离散定态”和“微观粒子碰撞/散射”为核心，**严禁机械套用力学默认的 `timed` 模式**：

| 近代物理场景类型 | 适用模式 | 决策理由与典型案例 |
|-----------------|---------|-------------------|
| **光电效应与双图像探究** | `controlsMode: 'param'` | 调节光频 ν、光强 P、电压 U 探究 I-U 曲线与 Ekm-ν 极限线，属于连续稳态响应，无需 10 秒倒计时进度条 |
| **玻尔原子理论与能级跃迁** | `controlsMode: 'param'` | 切换初末能级 n 观察轨道跳变、自发辐射光谱线与能级阶梯，属于分立定态跃迁 |
| **普朗克黑体辐射与能量子** | `controlsMode: 'param'` | 调节黑体温度 T 观察辐射强度与峰值波长移动，稳态辐射光谱图 |
| **物质波与电子衍射实验** | `controlsMode: 'param'` | 调节加速电压 U 观察德布罗意波长 λ 与衍射同心环半径缩放，稳态衍射图样 |
| **α 粒子散射实验与核式模型** | `controlsMode: 'timed'` | 粒子自左向右飞入金箔并发生库仑偏转的动力学过程，需要时序轨迹演化与大角度粒子统计 |
| **康普顿散射微观碰撞过程** | `controlsMode: 'param'` 或 `'timed'` | 单次碰撞过程用 action 触发或 timed；散射角 θ 与波长增量探究用 param |

> ❌ **严禁违规**：禁止在光电效应伏安特性、玻尔能级阶梯、黑体辐射温度曲线页面配置 `controlsMode: 'timed'`！这会在底部产生毫无物理意义的 10 秒倒计时条。

## ⚡ 二、跨 15 个数量级尺度与视景坐标映射铁律

近代物理同样具有极端的跨微观尺度：
- 原子与玻尔轨道尺度：$r_1 = 0.53 \times 10^{-10}\text{ m}$ (0.53 Å)
- 原子核尺度：$R \sim 10^{-15}\text{ m}$ (1 fm)
- 光频与能量尺度：$\nu \sim 10^{14}\sim 10^{15}\text{ Hz}$，$E \sim 1\sim 15\text{ eV}$，$h = 6.63 \times 10^{-34}\text{ J}\cdot\text{s}$
- 德布罗意波长尺度：$\lambda \sim 10^{-10}\sim 10^{-12}\text{ m}$ (pm)

**若按真实米数设置 SceneScale，浮点精度崩溃、微观原子核与轨道将缩为 0。**

### ✅ 规范架构：双层映射机制
1. **物理计算层（Hook / quantities / physics）**：
   - 必须采用严格的标准微观物理单位：光频用 $10^{14}\text{ Hz}$，能量用 $\text{eV}$，波长用 $\text{nm}$，电压用 $\text{V}$，电流用 $\mu\text{A}$，逸出功用 $\text{eV}$；
   - 物理计算函数严守纯函数，禁止四舍五入抹杀微小量，输出给右屏 `PhysicsPanel` 看板的数值必须 100% 真实准确；
2. **视景呈现层（Scene / Layout）**：
   - **玻尔轨道**：以设计坐标系中心为原点，轨道半径 $r_n$ 支持“等比示意比例（如 $r_n \propto \sqrt{n}$ 或等间距）”与“真实物理比例（$r_n = n^2 r_1$）”双模式切换；
   - **光电管与极板**：采用设计像素尺寸（如极板间距 120px），光子束与光电子采用密集粒子点云模拟；
   - **α 粒子散射**：金原子核居中固定，入射粒子按碰撞参数 $b$ 沿双曲线渐近线计算库仑斥力轨迹，在设计坐标系中等比映射。

## ⚡ 五、新高考四大近代物理核心模型交付标准

### 1. 光电效应双图判读模型（I-U 图 + Ekm-ν 图）
- **爱因斯坦光电效应方程**：$E_{km} = h\nu - W_0 = eU_c$
- **双图并列与物理量对应**：
  - **$I-U$ 伏安特性图**：
    - 反向遏止电压截距：$U = -U_c$，对应电流 $I=0$。遏止电压只与入射光频率 $\nu$ 及金属材料有关，与光强无关；
    - 正向饱和光电流平台：$I = I_m$。饱和电流与入射光强成正比；
  - **$E_{km}-\nu$ 最大初动能-频率图**：
    - 斜率：恒为普朗克常量 $h$（所有金属图线彼此平行！）；
    - 横轴截距：截止频率（极限频率）$\nu_0 = W_0/h$；
    - 纵轴反向截距：负逸出功 $-W_0$。
- **金属切换**：提供常用金属逸出功预设（铯 1.9 eV、钠 2.3 eV、锌 3.3 eV、钨 4.5 eV），观察曲线平行平移。

### 2. 氢原子能级跃迁与谱线计数模型
- **能级公式**：$E_n = \frac{E_1}{n^2}$（基态 $E_1 = -13.6\text{ eV}$，$r_n = n^2 r_1$）
- **跃迁辐射光子数对比**：
  - 一群处于 $n$ 能级的氢原子：最多辐射光子种数 $N = C_n^2 = \frac{n(n-1)}{2}$；
  - 单个处于 $n$ 能级的氢原子：最多辐射光子种数 $N_{\max} = n - 1$；
- **激发机制物理本质区别**：
  - 光子照射激发：光子能量必须**严格等于**两能级差（$h\nu = E_m - E_n$），或 $h\nu \ge |E_n|$ 发生电离；否则完全不吸收；
  - 电子碰撞激发：高速电子动能只需满足 $E_k \ge E_m - E_n$，碰撞后电子带走剩余动能。
- **光谱线系**：巴耳末系跃迁至 $n=2$（包含 4 条可见光谱线 $H_\alpha, H_\beta, H_\gamma, H_\delta$），赖曼系跃迁至 $n=1$（紫外区）。

### 3. α 粒子散射实验与原子核式结构模型
- **实验现象保真**：
  - 绝大多数 $\alpha$ 粒子穿过金箔方向几乎不变（偏转角极小）；
  - 少数 $\alpha$ 粒子发生较大偏转；
  - 极少数 $\alpha$ 粒子（约 1/8000）偏转角超过 $90^\circ$，甚至反弹（接近 $180^\circ$）。
- **核式模型结论**：
  - 原子中心有一个极小的原子核，集中了原子的几乎全部质量和所有正电荷；
  - 否定了汤姆孙枣糕模型；估算核半径数量级 $10^{-15}\sim 10^{-14}\text{ m}$。

### 4. 粒子的波动性与德布罗意物质波模型
- **物质波假说**：$\lambda = \frac{h}{p} = \frac{h}{mv}$
- **加速电场与波长**：$qU = \frac{1}{2}mv^2 \implies \lambda = \frac{h}{\sqrt{2mqU}}$
- **电子显微镜原理**：加速电压 $U$ 越高，电子动量 $p$ 越大，物质波波长 $\lambda$ 越极短，衍射现象越微弱，分辨本领远超光学显微镜。
