# OPTICS_RULES.md — 光学（几何与波动）工程与教学规范

> 本文件是光学领域（几何光学、波动光学、激光与光的本性）的权威工程与教学规范。
> 涉及光学场景新建、重构与高考功能开发时必须严格遵守。

---

## ⚡ 一、controlsMode 决策铁律

光学现象绝大多数属于**麦克斯韦定态空间分布**（稳定干涉条纹、衍射斑、偏振消光、折射反射光路），**严禁机械套用力学默认的 `timed` 模式**：

| 光学场景类型 | 适用模式 | 决策理由与典型案例 |
|-------------|---------|-------------------|
| **单缝/圆孔衍射、泊松亮斑** | `controlsMode: 'param'` | 衍射是稳态光强分布，用户拖动缝宽 $a$ 或波长 $\lambda$ 查看条纹宽窄，无需 10 秒倒计时进度条 |
| **薄膜干涉 / 增透膜 / 劈尖 / 牛顿环** | `controlsMode: 'param'` | 纯参数探索（膜厚 $d$、劈尖角 $\alpha$、凹凸缺陷），定态干涉图样 |
| **光的偏振（起偏/检偏/3D眼镜/滤光）** | `controlsMode: 'param'` | 旋转偏振片角度即时改变透射光强，由学生自主调节，无时间轴 |
| **光的反射 / 折射 / 全反射 / 透镜成像** | `controlsMode: 'param'` | 改变入射角 $i$ 或物距 $u$ 即时重绘光路，属于静态几何光路 |
| **连续波前扩散 / 光波振动连续流动** | `controlsMode: 'loop'` | 仅当需要向学生展示相干光波波前持续向外扩散干涉时使用 `loop`（永续循环，无倒计时） |
| **光的色散与光谱综合对比** | `controlsMode: 'param'` | 横向对比七彩光物理量与三棱镜偏折角，静态数据与光路图 |

> ❌ **严禁违规**：禁止在稳态光学页面配置 `controlsMode: 'timed'`！这会在底部产生毫无物理意义的播放器进度条与 10 秒倒计时。

## ⚡ 二、跨 7 个数量级尺度与视景坐标映射铁律

在真实物理中，光学具有极其悬殊的跨尺度特性：
- 光波波长 $\lambda \sim 10^{-7}\text{ m}$ (400 ~ 700 nm)
- 缝宽 / 劈尖膜厚 / 双缝间距 $d \sim 10^{-4}\text{ m}$ (0.1 ~ 0.5 mm)
- 缝屏距离 / 传播距离 $L \sim 10^0\text{ m}$ (1 ~ 2 m)
- 条纹物理间距 $\Delta x \sim 10^{-3}\text{ m}$ (数毫米)

**若按 1:1 物理米数绘制，0.2mm 的双缝在 840px 画布上只有 0.16px，波长更只有 0.0005px，完全无法呈现。**

### ✅ 规范架构：双层映射机制
1. **物理计算层（Hook / physics）**：
   - 必须采用严格的真实 SI 物理单位（nm, mm, m）计算；
   - 输出真实物理量：条纹间距 $\Delta x = \frac{L}{d}\lambda$ (mm)、光程差 $\delta$ (nm)、透射光强 $I$ (%)、临界角 $C$ (°)；
   - 确保右屏 `PhysicsPanel` 看板中显示的数值 100% 真实准确。
2. **视景呈现层（Scene / Layout）**：
   - **光具几何布局**：光源、透镜、挡板、观察屏在设计坐标系（840×650）下采用清晰的几何示意排布；
   - **动态保真映射**：视景中的条纹宽度与光程差必须严格正比于物理量，即 $fringeSpacingPx \propto \frac{L}{d}\lambda$，保持参数调节时的物理定性规律 100% 保真；
   - ❌ **严禁虚假参数**：严禁在 `useSceneScale` 中胡乱填入 `physicsWidth: 8.4, physicsHeight: 6.5`（纯粹凑数应付校验）。若全场景基于设计坐标布局，直接遵循设计坐标并在组件内做局部比例映射。

## ⚡ 三、色彩语义与光谱映射铁律

1. **光线颜色与物理波长强绑定**：
   - 严禁使用力学颜色（如 `PHYSICS_COLORS.velocity` 蓝色 `#2563EB`、`PHYSICS_COLORS.forceNet` 橙色 `#EA580C`）代表光线；
   - 单色光光线、波前和光屏条纹颜色必须由真实波长计算获得：
     ```ts
     import { wavelengthToHex } from '@/physics/optics'
     const lightColor = wavelengthToHex(wavelength) // 400nm 蓝紫 -> 700nm 红
     ```
2. **白光干涉与色散**：
   - 白光包含连续光谱，中央为白色（光程差零），两侧必须呈现“内紫由外红”的彩色彩带；
   - 严禁将白光简单画为单根黄线或白块。
3. **光学器材材质色彩**：
   - 光学镜片、玻璃砖、三棱镜使用 `OPTICS_COLORS.lens` 与 `OPTICS_COLORS.lensStroke`；
   - 挡板、小孔、狭缝使用 `SCENE_COLORS` 或高对比度暗色边框；
   - 观察屏背景使用深色（如 `#0a0e17` 或 `#000000`），确保光强与干涉亮暗条纹清晰可辨。

## ⚡ 四、图表与光强空间分布规范

1. **光强分布曲线 $I(y)$ / $I(\theta)$ 与条纹对齐**：
   - 双缝干涉：光强曲线为余弦平方分布 $I \propto \cos^2\left(\frac{\pi d y}{\lambda L}\right)$，各级亮纹等高等宽；
   - 单缝衍射：光强曲线为辛克平方分布 $I \propto \left(\frac{\sin\beta}{\beta}\right)^2$，中央亮斑宽度是其他各级的 2 倍，光强集中 90% 以上；
   - 圆孔衍射：光强为艾里斑一阶贝塞尔曲线 $I \propto \left(\frac{2J_1(x)}{x}\right)^2$；
   - 光强曲线的主极大、极小点必须与屏上干涉/衍射条纹的亮带、暗带中心严格在同一水平线（相位对齐）。
2. **偏振马吕斯定律曲线**：
   - 必须展示透射光强随偏振片相对夹角 $\Delta\theta$ 变化的 $I = I_0 \cos^2\Delta\theta$ 曲线，并在 $0^\circ$（最大透射）、$90^\circ$（完全消光）做显式标记。

## ⚡ 五、新高考高频考点三屏落地标准

1. **主屏禁止大段文字**：
   - 屏幕上仅允许出现符号与数值标注（如 $S_1, S_2, d, L, \Delta x = 3.25\text{ mm}$），禁止在画布中手写段落总结。
2. **右屏必须覆盖的高考考点**：
   - **双缝干涉**：相干光条件、光程差条件（$k\lambda$ 亮纹、$(2k+1)\frac{\lambda}{2}$ 暗纹）、条纹间距公式 $\Delta x = \frac{L}{d}\lambda$；
   - **薄膜干涉**：等厚条纹判据、增透膜 $d = \frac{\lambda}{4n}$、劈尖干涉表面缺陷检测（“凹向薄端，凸向厚端”）；
   - **单双缝对比**：双缝等宽等亮 vs 单缝中央宽亮两侧窄暗；
   - **偏振**：横波证明，横波有偏振、纵波无偏振。
3. **左屏控制台预设规范**：
   - 提供典型真题一键预设（如 2021 山东高考劈尖凹坑预设、理想增透膜预设），通过 `controlMeta.preset` 声明，禁止手写散乱按钮。
