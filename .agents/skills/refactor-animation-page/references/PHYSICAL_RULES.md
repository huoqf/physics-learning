# 物理仿真保真度规范 (PHYSICAL_RULES)

> 本文件供重构或开发涉及**矢量、场、电磁学、波动、状态方程**等复杂物理场景时按需读取。

---

## 1. 矢量方向与坐标系心智模型

| 易错场景 | 根因陷阱 | 强制规范 |
|---------|---------|---------|
| **矢量绘制** | 混淆 SVG 屏幕坐标（y 向下为正）与物理坐标（y 向上为正） | `VectorArrow` 的 `vector` 遵循**物理笛卡尔坐标系**（`y > 0` 向上，`y < 0` 向下）。屏幕向下位移必须传负值（如 `{ x: 0, y: -1 }`）。 |
| **闭合回路环流** | 单独写各支路箭头，局部视角导致电流方向打架 | 任何回路电流必须全链路闭合验算（例如顺时针回路：顶边向左 $\leftarrow$、底边向右 $\rightarrow$、左边垂直向下 $\downarrow$、右边垂直向上 $\uparrow$）。 |
| **绕组与场线咬合** | 箭头画在背面半环，或正面绕向与内部磁场反向 | 1. 绕组微箭头必须落在**正面可见半环**（例如椭圆弧凸向观察者一侧）；<br>2. 必须以右手螺旋定则（安培定则）严密推导：四指弯向正面电流方向，大拇指指向线圈内部磁场方向（指向 N 极）。 |

## 2. 三维波形与多维场 2D 投影

- **严禁指标过拟合式的假同相**：
  在斜二测等二维立体投影中，严禁通过将投影水平偏置绑定到波长（如 `min(..., lambda * k)`）来消除视差。这会导致高频下投影角塌缩为 90° 垂直正弦波，摧毁立体几何真实性。
- **三维正交透视三件套**：
  1. **恒定投影方向角**：保持固定透视夹角（如 $\approx 125^\circ$，固定的 `dx, dy` 比例）；
  2. **原点三维参考坐标架**：在波源起点处完整呈现 $E$（竖直轴）、$B$（斜向透视轴）、$c$（传播轴）三轴交汇体系；
  3. **同截面正交微矢量与贯穿虚线**：在波峰与关键节点处，由中轴同一空间点 $x$ 同时引出 $E$ 与 $B$ 矢量，并用正交投影虚线贯通，直观标示“同一截面两场完全同相同步”。

## 3. 单一可信源原则 (SSOT)

- **物理计算禁止在渲染层分裂**：
  阻尼衰减系数、电磁能量转换、临界判断公式必须收敛在 `src/physics/` 层唯一导出函数中。
- **杜绝 UI 截断与数据看板打架**：
  数值格式化逻辑（如极小残差归零阈值、保留小数位数）必须由物理领域工具函数统一提供（例如 `formatLCEnergy`），中屏图表与右屏 Quantity 看板必须消费同一来源。

---

## 4. 动画路由与看板注册一致性

- **注册表完整映射**：
  动画在 `src/data/registries/` 注册后，必须在 `src/data/physicsQuantities.ts` 的 `quantityRegistry` 中补齐对应 entry，严禁首帧或场次切换时退化为裸英文键名兜底。
- **元数据同步**：
  `src/ANNOTATIONS.md` 中的 Scene 组件与图表组件映射必须随重构重命名实时更新。
