# 2026-W31 工程日志（07-28 ~ 08-02）

## 页面壳布局跳变修复（08-02 完成）

**问题**：远距离输电等动画页初始画面偏小，点击播放后画面跳变放大（scale 0.865→0.945），伴随页面溢出 29px、顶栏压扁。

**根因**（两层叠加）：
1. **页面壳 flex 超售**：`AnimationPage` 容器 `calc(100vh - 56px)` + 顶栏 `h-14`(56px) + ThreePanel `h-full` = 超售 56px，初始按比例收缩，播放后右面板内容增长导致 ThreePanel 拒绝收缩 → 跳变
2. **右面板懒加载竞态**：`buildPhysicsQuantities` 懒加载完成后无重渲染触发，右面板停留短小兜底参数；点播放触发首次重渲染 → 切换为完整长公式 → 布局跳变

**验证**：Playwright 在 1366×768 中屏实测，量化初始→播放后布局链数据

**修复方案**（3 个 shell 文件，零动画组件改动）：

- **方案A — 布局正确性修复**：AnimationPage 顶栏 `shrink-0`，ThreePanel `h-full` → `flex-1 min-h-0`
  - 效果：顶栏 56px，ThreePanel 稳定 656px，画布 558（scale 0.858），**永不跳变、零溢出**
- **方案B — 竖向空间回收**（在 A 之上）：顶栏 `h-14` → `h-11`，控制栏紧凑化
  - 效果：画布 558→600，scale 0.858→**0.914**，接近跳变后 0.945，且无溢出
- **方案C — 右面板竞态修复**：RightPhysicsPanel 内 preload 完成后补一次重渲染，消除兜底参数→完整物理量的内容跳变

**验证**：Playwright 逐帧确认布局链稳定，顶栏恢复 56px、页面零溢出、中屏画面无跳变

**涉及文件**：`AnimationPage.tsx`、`ThreePanel.tsx`、`AnimationControls.tsx`
