## 一、实验部分：你的纠偏成立，我的原判有事实错误

### 1.1 胡克定律 —— 我判错了，已改

我原文写"完全缺失（❌ 无）"。实测：

- `registries/mechanics-experiment.ts` 的 `anim-mechanics-experiment-base` 有 `mode` 三选一，第 3 项即 **`③ 胡克定律探究`**（`value: 2`），配套 `k`（劲度系数）与 `m`（钩码质量）参数，且 `paramMeta` 里明确写了"上限对应弹簧最大伸长量 14.7 cm（画布量程内）"；
- 还有预设 `📋 2022全国乙卷：胡克定律测劲度系数 k`（k=120 N/m、m=0.3 kg）；
- 另有 `anim-spring-force` mode 0 = `SpringForceHookeLawScene` + `HookeLawChart`，本身就是 F-x 图像探针。

即：**同一个实验做了两遍，一处挂在实验专题、一处挂在弹力知识点**。我漏看了 mode 枚举，只按"知识树标题"判断覆盖，这是方法错误——**用节点标题而不是动画能力来判覆盖**。已修正报告 1.2、1.4、〇节、第 4 批共 4 处。

### 1.2 力的合成 —— 成立，但措辞要准

`anim-vector-addition` 的 `defaultParams` 是 `{ f1, f2, angle, phi, mode }`，`controlsMode: 'param'`——是**参数滑块**而非画布拖拽。功能上等价（可连续改变大小与夹角、实时给平行四边形与三角形合成），结论"无需新建页"成立，只是"自由拖拽"这个描述与实际交互形态不符。若要贴"拖拽"体验，改的是 Scene 的手柄，不是新建页面。

### 1.3 电容器 —— 方向对，但"已覆盖"过头

`anim-capacitor` 确有 `connected` 双态（连电源 U 恒定 / 断电源 Q 恒定）、`S/d/εᵣ` 三个可调量、静电计张角读数。这部分是**准静态**覆盖，做得没问题。

但人教版"观察电容器的充放电"这个实验的教学内核不是"稳定后 Q、U、E 是多少"，而是**过程**：i 随时间衰减、u 随时间上升、**i-t 曲线下面积等于 Q**、时间常数 τ=RC。这些当前一帧都没有。所以我的原判应改为：

> 不是"缺实验页"，而是**缺暂态过程**；应作为 `anim-capacitor` 的进阶模式补 `i-t / u-t` 曲线与面积积分，**不新建页面**。

已按此口径改报告。这也印证你的产品原则，只是"是否已覆盖"要按**教学内核**判，不按"有没有那个开关"判。

### 1.4 平抛/向心力 —— 认同理念，保留一条工程意见

"调初速看射程、调 r/ω 看 F"确实超越了传统实验室的机械测量，我同意不必拆"理论页/实验页"。

## 二、代码 P0 核对：12 成立 / 1 不成立 / 1 需改口径

### 2.1 P0-12① 安培力方向 —— **不成立**（实机判定）

你写"`F=-BIL`（负向向左），而导轨电源正极在上、磁场向里，左手定则合力应向右"。

实机 `/#/animation/anim-ampere-force`（默认 I=2A、B=1T、L=4m）：

- 右屏明写 `电流 I = 2.0 A (向上)`；
- 场景标注 `匀强磁场 B = 1.0 T (垂直纸面向里)`；
- `F 安` 箭头**向左**，看板 `安培力 F = 8.00 N (向左)`。

左手定则复核：磁感线垂直纸面向里穿入手心（手心朝读者外），四指指向电流方向（向上），**拇指指向左**。→ **F 向左是正确的**，`F = -B·I·L` 与"电流向上"自洽。原判把"电流向下"当成了前提，方向推断有误。

**但这一页确实有问题，只是位置不同**：

`DCSource.tsx:470-471` —— 垂直摆放时 `polarity='right-positive'` 被解释为"**正极在上**"。而 `BasicAmpereScene.tsx:75` 对 `I>=0` 就传 `'right-positive'`。于是按电路拓扑：电流自上方正极流出 → 沿上导轨 → **从导体棒上端流入、向下流** → 与右屏"电流向上"直接矛盾。

定性：**电源极性与电流标注不一致**（同一个页面里电流有两个方向），而不是安培力公式错。修复只需二选一：把 `polarity` 随电流方向改为 `top-positive` 映射，或把棒内电流标注改"向下"并让 F 反号。**不能两处都改**。

### 2.2 P0-12② 磁场圆周偏转 —— **成立**（实机判定）

实机 `/#/animation/anim-magnetic-circular-geom`（正电荷 +q、B=1T 垂直纸面向里、v=3m/s、入射角 60°）：

- 看板 `轨道半径 R = 3.00 m`、`运动周期 T = 6.28 s`（R=mv/qB、T=2πm/qB 都对）；
- `出射时间 t = 2.09 s`。2.09 s × 1 rad/s = 120° = **2α**（α=60°），这是"圆心在边界外侧"的**短弧**解；
- 画面虚线轨迹：从入射点向右上拱起、在边界右段回落，弧的圆心落在 y<0（磁场外）。

正确物理：+q 在 ⊗ 场中，v 沿 60° 方向时 F = qv×B 指向左上，**圆心应在 y>0（场内）**，出射弧角应为 2π−2α = 240° → **t = 4.19 s**。当前轨迹是它的镜像。

根因：`CircularGeometryModel.tsx:44/71/83` 的 `omegaDir = -particleSign * omega` 与 `worldToDesign` 的 y 翻转叠加后，方向没有回正。修 `omegaDir` 符号需同时复核 `theta0`、出射速度分量 `vxOut/vyOut` 的三处派生量，**不是单行改动**。

### 2.3 P0-13 闭合电路电流方向 —— **成立**（实机 + DOM 双证）

- DOM 取极性标注：`'-'` 在 x=320、`'+'` 在 x=360 → **正极在右**；
- `ClosedCircuit.tsx:112-121` 四个方向的 polygon：顶路 apex 248 > base 240（向右）、右路 apex 93 > base 85（向下）、底路 apex 582 < base 590（向左）、左路 apex 137 < base 145（向上）→ **顺时针环流**；
- 顺时针意味着沿底部导线向左流入 `+` 极（x=360），即"电流灌入正极"。

应全反向（逆时针）。注意是**七处 polygon 逐个反向**，不是改一个常量。

### 2.4 P0-14 碳-12 质量 —— **成立**

`features/modern/nuclear-reaction/model/constants.ts:22`：`碳-12 mNucleus: 12.000000`、`eBinding: 89.09`。

对照同表其它核素：氘 2.013553、氚 3.015500、氦-4 4.001506、铀-238 **238.000300**——这些用的都是**核质量**（U-238 原子质量 238.0508 − 92mₑ = 238.0003 ✓）。唯独碳-12 填了原子质量（应为 11.996709）。故 E_b 少 6mₑc² ≈ 3.07 MeV，得 89.09 而非教材 92.16，且与同页比结合能曲线 7.68 MeV/A 互斥。**只此一条错，其余核素正确**。
