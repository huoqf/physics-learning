# 兜底看板标签串域修复（第 3 项，2026-10-20）

问题：右屏看板在物理量构建器异步加载完成前，用一张**全局**"裸键 → 中文名"映射表
（`COMMON_PARAM_LABELS`）猜标签。它只按 key 查、不看动画，同一个键在不同动画里指向
不同物理量，于是必然串域：

| 页面 | 参数键 | 旧显示 | 实际含义 |
|---|---|---|---|
| 板块模型 | `L = 2.50` | **电感 L** | 木板长度 |
| 远距离输电 | `k = 0.02` | **劲度系数 k** | 降压变比 n₄/n₃ |
| 远距离输电 | `r = 10` | **内阻 r** | 线路电阻 |
| 各页 | `mu1` `angle` `advancedMode` `modelIdx` `deltaT` … | 裸英文键 | 未收录 |

根因不是"映射表不全"，而是**映射的作用域错了**：注册表的 `paramMeta` / `controlMeta`
里本来就写好了每个键的中文名与单位，兜底却另造了一份、且丢了动画上下文。这是又一处
双真源。

---

## 一、改法

### 1. 新增 `src/data/paramVocabulary.ts`

把"键 → 中文名 + 单位"的权威来源收回到**动画自己的声明**：

- 收录 `paramMeta`（连续可调物理参数，标签与单位最完整）；
- 收录**有中文名**的 `segmented` / `modeGrid`（离散物理场景量：木板长度、电流方向…）；
- 不收 `toggle` / `preset` / `tip` / `action` / `storeToggle`（交互与显示开关，不是物理量）；
- **没有 `label` 的 segmented 也不收**——斜抛的 `advancedMode` / `viewMode` 是模式档位，
  若拿键名当标签，看板会重新长出英文；
- 词表外的键一律不显示（`modelIdx`、`deltaT` 这类实现细节对学生无意义）。

同一模块还承载 `matchesConditionValue` / `isEntryVisible`，从 `ControlPanel.tsx` 提炼出来，
左屏控件过滤与右屏兜底共用一份 `showIf` / `hideIf` 求值——否则又是一处双实现。

### 2. `physicsQuantities.ts`

- 删除 `COMMON_PARAM_LABELS` 整张表；
- `buildPhysicsQuantities(animId, params, time, lastChangedParam, vocabulary?)` 新增第 5 个可选参数；
- 兜底改为 `buildFallbackPanel(params, vocabulary)`：**遍历词表**而不是遍历 `params`，
  词表缺失时返回空数组。

原则：**词表缺失宁可为空，也不按键名猜标签**。空白比"电感 L"诚实。

### 3. `AnimationPage.tsx`

`RightPhysicsPanel` 新增 `paramMeta` / `controlMeta` 两个 props（页面本来就已经用
`config.buildParamMeta` 算好了 `paramMeta`，直接传下去），内部 `useMemo` 建词表。

### 4. `ControlPanel.tsx`

删除本地 `matchesConditionValue` / `isControlVisible`，改用共享的 `isEntryVisible`。
行为不变（原实现逐行等价搬迁）。

## 二、验证

### 兜底帧实机抓取

用 `location.hash` 切换 + 20 ms 轮询，抓到构建器解析前的真实兜底帧：

| 页面 | 兜底帧（ms） | 内容 |
|---|---|---|
| 远距离输电 | 142 ms | `输电电压 U₂ 11.00 kV` / `发电功率 P₁ 100.00 kW` / `线路电阻 r 10.00 Ω` |
| 斜抛 | 101 ms | `初速度 v₀ 20.00 m/s` / `抛射角 θ 45.00 °` |

关键点：`k`、`N`（受 `showIf: mode=1` 控制）在基础模式下不再出现；`showIdeal`、
`peakLoad`、`mode`、`advancedMode`、`viewMode`、`g` 等未声明键全部消失；单位
（kV / kW / Ω / m/s / °）来自 `paramMeta.unit`，旧实现恒为空串。

### 左屏 showIf 未受影响

进阶模式下 `用户户数 N (户)` 与 `降压变比 k=n₄/n₃` 正常出现；该模式下
`P₁=480.2 kW / I=43.65 A / ΔU=436.5 V / P_loss=19.05 kW / U₃=10563.5 V / U₄=211.3 V`
逐项自洽（I=P/U₂、ΔU=I·r=436.5、P_loss=I²r、U₄=U₃·k）。

### 新增守卫测试

`tests/data/paramVocabulary.test.ts`（9 条）：

1. 板块模型 `L` → `木板长度`，词表内不含"电感"；
2. 板块模型 `mu1/mu2/v0` 沿用 `paramMeta` 完整标签与单位；
3. 输电 `k` → 含"降压变比"，词表内不含"劲度系数"；
4. 输电基础模式下 `N`/`k` 按 `showIf` 隐藏，`U₂` 单位为 `kV`；
5. 斜抛未声明标签的模式档位不进词表（`advancedMode`/`viewMode`/`showPrevTrajectory`）；
6. 斜抛切阻力模式后 `空气阻力 k`（`kg/m`）才出现；
7. 未知动画兜底为空；
8. 兜底只输出词表内的键（`modelIdx` 等被丢弃），单位正确；
9. **全量守卫**：124 个动画的默认参数都能解析出非空、且标签不等于键名的词表。

> 第 9 条需要枚举全部动画，为此在 `animationRegistry.ts` 增加 `getAllAnimationIds()`
> （测试/工具用，调用前需 `ensureExtendedRegistry()`）。

`tests/data/physicsQuantities.test.ts` 里"未知动画回退为参数键值列表"一条按下述新契约改写：
未知动画没有任何声明 → 兜底为空。

**结果**：`npx tsc --noEmit` 通过；`vitest` 96 文件 / 1155 测试全通过（较改前 +9 条）。
