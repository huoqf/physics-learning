## 三、本次修复的 6 个缺陷

### D1 `OilFilmScene` 方格宽度硬编码 22px（真·渲染 bug）

循环按 `cellSize` 步进，`<rect width={22} height={22}>` 却写死。改了 `cellSize` 之后
方块尺寸不变 → 格子互相重叠或留缝，"1 cm 方格"这件事在画面上根本不成立。

改为 `width={cellSize} height={cellSize}`。

### D2 方格计数用 0.88 / 1.08 两个魔法系数（数出来的格数和读数打架）

旧判定：`dist <= R*0.88` 记满格、`dist <= R*1.08` 记半格。默认参数下实机数：
**172 满格 + 89 半格 = 261 格**，而看板写 `N = 223 格`；极端参数（稀释比 200、40 滴/mL）
看板写 1116 格，画面上只有 **339** 个格子。

改为：
1. 油膜轮廓的起伏函数 `filmEdgeWobble(angle)` 提成模块级函数，多边形与格点判定共用；
2. 由"多边形面积 = 物理面积"反解像素半径
   `R = sqrt(S(cm²) × (1cm 的像素数)² / 单位轮廓面积)`（单位轮廓面积用鞋带公式算）；
3. 方格判定改成"格心是否落在轮廓内"（= 教材的"超过半格算一格"），
   再按边界距离做 ±几格的微调，保证**图上填色格数严格等于看板 N**；
4. 浅盘缩放规则改成"油膜（含起伏）装得下就不缩放，装不下按比例缩小"，`pxPerCm` 与格边共用一把尺子。

实机：默认 **223 格 = 223 个填色格**，极端 **1116 格 = 1116 个填色格**，格边 23.3px → 10.4px。

### D3 `celestial.ts` 的 JSDoc 被截断

插入常量块时把上一段注释的 `/**` 留成了未闭合状态，`@param` 与后面几段注释串成一团。
已重写为一段完整注释，并补上"F/a 必须由本函数给出，不得再用真实 G 另算"的说明。

### D4 交变电流看板把「度」当「弧度」用（中屏/看板仍会分叉）

注册表里 `initialPhase` 的单位是 `°`（0–360，step 15），中屏做了 `×π/180`，
看板 `ac.ts` 却写 `theta = omega * time + initialPhase` 直接把度数加进相位。
`θ₀ = 90°` 时看板相位凭空多出 90 rad ≈ 5157°，Φ 的正负号都会反。

改为看板调用同一个 `computeACGenerationState()`，换算只在一处做，公式、瞬时值、中性面判定全部同源。

### D5 `MiniChart` 图例固定 `toFixed(1)`（Φ 全显示成 0.0）

Φ ≈ 0.02 Wb、BS 参考线 0.02 —— 图例一律显示 `0.0`，学生读不出任何东西。
给 `MiniChartLine` / `MiniChartStaticLine` 加可选 `valueDigits`（默认 1，向后兼容），
交变电流页 Φ 用 4 位、e 用 2 位，与看板读数一致（`Φ (Wb): 0.0174 / +BS: 0.0200`）。

### D6 交变电流图表在拖动进度条后空白

历史点在 render 里 push 且只在播放时累积：暂停后拖动进度条，看板有数、两条曲线全空。
Φ(t)、e(t) 都是闭式函数，改为按 `[tMin, tMax]` 解析采样 240 点，由 MiniChart 在游标处裁剪。
播放 / 暂停 / 拖动 / 重置四种状态都只取决于当前 `time`，不再有渲染期副作用。

顺带把 `calculatePhotocurrent`（#8）的归一化做掉：`I(0⁻) = I_max`，
消除 U=0 处随遏止电压变化的 2.4%~28.7% 竖直跳变。
