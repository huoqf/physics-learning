# physics-learning 知识树完整性与动画教学有效性审查

- 日期：2026-10-20
- 范围：`src/data/knowledge/**`（144 个知识节点）、`src/data/registries/**`（124 个动画）、`src/physics/**`（物理层）、`src/data/quantities/**`（右屏看板）
- 方法：
  1. 用脚本导出知识树全量节点 + 注册表全量动画，做**双向引用交叉校验**（断链 / 孤儿 / 无动画节点）；
  2. 以人教版 2019（必修一~三、选择性必修一~三）逐章逐节对照知识树；
  3. 124 个动画按 9 个模块分组逐页读源码（注册表参数 → Animation → Scene → physics 计算），**按 defaultParams 代入数值验算**并与页面显示值比对；
  4. 对判定为 P0 的结论回源码逐条复核（下文标注"已复核代码"或"待目视复核"）。
- 本次审查**未修改任何源码**。

### 1.5 知识树结构问题（非内容缺失）

1. **10 个节点无动画**：质点与参考系、位移、牛顿第一定律、牛顿第三定律、运动的合成与分解、机械能守恒应用、动量守恒应用、等量电荷场线模型、黑体辐射、德布罗意波。
   其中 **牛顿第一/第三定律** 是必修一的概念基石，"惯性"与"作用力反作用力"完全靠文字，与"交互动画"的产品定位不符——但这两个定律本身不适合做过程动画，可用"对比判错"式交互（如"马拉车"受力辨析），优先级 P2。
2. **前置链断裂**：`electricity-4-1`（电磁感应）prerequisites 指向安培力，跳过磁通量；`electricity-1-1`（库仑定律）无前置，跳过电荷。补 1.3 的两个 P0 节点即可修复。
3. **章节编号不连续**：`mechanics-5.5`、`mechanics-3-method-1`、`electricity-3-3-geom` 等自定义编号混用，`buildKnowledgeTree` 若按 id 排序会错位（本次未见实际错位，属隐患）。
