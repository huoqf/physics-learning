## 二、执行明细

### ① 多用电表公式/警示随挡位分派

`src/data/quantities/experimentMultimeter.ts` 新增 `OHM_FORMULAS` / `DCV_FORMULAS` / `DCA_FORMULAS`
三组常量与 `formulasForRange()` / `warningsForRange()`，按 `calculateMultimeterCircuit()` 返回的
`rangeType` 分派：

| 挡位 | 公式 | 警示 |
|---|---|---|
| OHM | 欧姆表回路欧姆定律、欧姆调零满偏电流、中值电阻与半偏状态（原三条） | 测电阻前必须断开原电路、严禁带电测量 |
| DCV | 串联分压电阻 `R_V = U/I_g − R_g = (n−1)R_g`、电压表总内阻 `R_内 = U_满/I_g`、电压扩程倍数 `n = U/(I_gR_g)` | 电压挡并联、红笔接高电势、量程取满偏 1/3~2/3 |
| DCA | 并联分流电阻 `R_A = I_gR_g/(I−I_g) = R_g/(n−1)`、电流表总内阻 `R_内 = R_gR_A/(R_g+R_A)`、电流扩程倍数 `n = I/I_g = 1 + R_g/R_A` | 电流挡必须串联、严禁并在电源两端 |
| OFF | 空（分区自动隐藏） | 用毕归位：旋至 OFF 或交流电压最高挡 |

改警示的理由与改公式相同：切到 DCV 还挂着「测电阻前必须断开」，是同一处「与当前测量态脱节」。
