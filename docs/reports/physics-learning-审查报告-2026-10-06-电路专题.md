## 二、问题清单

> 优先级：P0 = 教学性错误（必须改）；P1 = 规范/一致性缺陷（应改）；P2 = 轻微或建议

### P0-1　滑动变阻器（限流式）滑片方向与"接入阻值"相反 —— 跨页面系统性教学错误

**现象（实测）**
- 闭合电路欧姆定律页：`R = 0.1 Ω`（最小值）时滑片停在电阻框**最左端**；`R = 20 Ω`（最大值）时滑片停在**最右端**。
- 串并联及动态分析页：`R₂ = 10 Ω`（量程 0–100）时滑片同样几乎贴最左端。

**为什么是错的**
`Rheostat.tsx` 限流式分支的接线是"**左端接滑轨、右端接电阻框**"（`path: M -73 0 → -42 0 → -42 sliderY → -36 sliderY`，右端 `boxW/2 → 73 0`）。因此实际接入回路的电阻是**滑片到电阻框右端**的那一段：

```
R_接入 ∝ (boxW/2 − wiperX)，   wiperX = -18·scale + ratio·36·scale
```

即 `ratio`（＝面板显示阻值）增大 → 滑片右移 → 接入阻值**减小**。当前实现把"阻值最大"画成了"接入段最短"，两者恰好相反。

**根因文件**：`src/components/Physics/Rheostat.tsx:88`（`symbolicWiperX`），配合 `:154-176` 限流式接线。该方向映射为**历史遗留**（`e95cdf2` 只改了线宽/配色与删除了"左端悬空"虚线提示，见下方 P1-4），但本轮"全面规范"未发现它。

**影响**：凡使用限流式滑动变阻器的页面（闭合电路、动态分析、测电动势内阻…）都会让学生观察到"阻值调大反而接入电阻变小"，与教科书结论直接矛盾。

**修复方向（二选一，都只动一处）**
1. 反转滑片：`symbolicWiperX = 18·scale − ratio·36·scale`（保持现有接线）；
2. 或改接线为教科书更常见的"**左下进 + 右上出**"：左外线接电阻框左端 `-boxW/2`，右外线接滑轨右端 `+36·scale`，此时 `R_接入 ∝ (wiperX + boxW/2)`，与现有滑片方向自洽。

建议同时补一条守卫/单测：给定 `value=min/max`，断言滑片 x 与"接入段长度"的单调关系。

### P1-1　新增的滑片"P"标号与页面标题文字重叠（"读数避让"未达标的反例）

**现象（实测截图）**：闭合电路欧姆定律页，`滑动变阻器 R = 20.0 Ω` 标题被红色 `P` 字压住（`R =` 处）；`R = 0.1 Ω` 时 `P` 压在"滑动变阻**阻**"上。

**根因（可算）**
- `Rheostat.tsx:201-211` 在 `y = sliderY − 6·scale` 处新增 `P`（本轮 `e95cdf2` 新引入）。`width=120 → scale=0.857`，`sliderY=-15.4` → `P` 基线 y≈29.5，字高 9 → 字框约 21–30。
- `ClosedCircuit.tsx:220-227` 的标题画在 `y = 50 − 28 = 22`，字高 11 → 字框约 13–25。
- 两者在 y∈[21,25] 区间必然重叠，且都是"元件上方标注"，无任何避让。

**修复方向**：`P` 的偏移改为**可配置**（或默认放到滑杆**下方/左侧**），或让宿主页面标题统一走 `layoutLabels` 做避让；至少对 `showLabel={false}` + 自绘标题的页面给出安全区约定。

### P1-3　多用电表页旋钮指示三角渲染失败（`polygon` 属性未插值）

**现象**
- 控制台报错（14 个电学页面扫描中唯一报错页）：`Error: <polygon> attribute points: Expected number, "0,-knobR -8,-knobR…"`
- 视觉：多用电表中央选择旋钮只有白色手柄，**红色指示三角缺失**，导致当前挡位指示不明确。

**根因**：`src/features/experiment/multimeter/components/MultimeterScene.tsx:376`

```tsx
<polygon points="0,-knobR -8,-knobR+12 8,-knobR+12" fill={...} />   // ← 普通字符串，变量未插值
```

应为模板字符串：`` points={`0,${-knobR} ${-8},${-knobR + 12} ${8},${-knobR + 12}`} ``。

来源 `81a93cf`（2026-09-25 电学实验批次），非本轮引入，但属于"电路部分"现存缺陷。

### P1-4　`ImpedanceFreqChart` 参考线标签与 X 轴刻度完全重叠

**现象（实测）**：电感电容页，X 轴刻度 `30.0` 被参考线标签 `f₀ 谐振点 (22.5 Hz)` 整体覆盖，两个数字都不可读。

**根因（DOM 实测坐标）**
- 绘图区 x：`f=0 → 64.97`，`f=150 → 934.7`（每 30Hz ≈ 173.95px）。
- `f₀=22.5Hz` 参考线 x = 195.47，其标签 `x=195.47, y=369.8`（**在 X 轴 353.19 之下的刻度文字行内**）；而刻度 `30.0` 的 x = 238.9，正落在该标签文字区间内 → 必然重叠。
- 另：游标标签起点 `x = cursorX + 6.4`，游标自身琥珀虚线（`#F59E0B`, dash `4 4`）从文字左侧第一/二个字符处穿过。

**修复方向**：参考线标签上移到绘图区内（`y < 353`）并做 `layoutLabels` 避让，或改为只画线不写长标签（把 `f₀` 值放进图例/看板）。

### P2-1　闭合电路 P-R 图游标读数与看板不一致（0.71W vs 0.82W）

**现象**：`E=6, r=2, R=0.1Ω` 时，图上游标写 `(0.1Ω, 0.71W)`，右屏"输出功率 P出 = 0.82 W"。

**根因**：`ClosedCircuitCenterExtra.tsx:39-49` 以 `steps=80` 在 `[0,20]` 上采样折线（步长 0.25），`:107` 的 `cursorLabel` 取的是**折线线性插值**。R=0.1 落在 (0,0)–(0.25, 1.778) 之间 → 0.711W；解析真值 E²R/(R+r)²=0.816W。R 落在采样点上时（如 R=10）则完全吻合。

**修复方向**：游标读数改为解析求值（或加密采样），保证"图线读值 = 看板值"。

### P2-2　非纯电阻页"卷扬机"框内的 η=50% 实为系统总效率

**现象**：卷扬机图标下写 `η = 50%`，紧邻 `P机 = 8.3 W`、`v = 1.70 m/s`（后者由 `v = P机/(mg)` 全量推出）。若按"卷扬机效率 50%"理解，则 `v` 应为 0.85 m/s，自相矛盾。

**根因**：`NonPureCircuit.tsx:150` 该行由 `e95cdf2` 新写，取值 `P_mech / P_total = 8.33/16.67 = 50%`，即**整机（电源→机械）总效率**，却被放进"卷扬机"标签框内。

**修复方向**：改标注为"系统总效率"并移出卷扬机框（或移到电动机/回路侧），避免学生误读为机械传动效率。

### P2-3　通电自感页：看板与曲线/场景"双真源"

**现象**：`E=12, RL=2, RA=6` 时，看板"纯阻灯泡电流 I_A = 2.00 A"，而中屏曲线（`iSteady`）与场景支路1稳态均为 **1.5 A**。

**根因**：两处模型不一致——
- 场景/曲线：`useSelfInductionPhysics.ts:78-105` 用 `rBranch = RL + RA = 8Ω` → 两支路稳态同为 1.5A（这正是"通电自感两灯稳态等亮"的实验前提）。
- 看板数据：`src/data/quantities/electromagnetism/selfInduction.ts:26-28` 用 `iLamp = E/RA = 2.00A`、`calcTurnOnCurrent(time, E, RL, L)`（支路总阻只算 RL → 稳态 6A）。

**影响**：稳态时看板与曲线差异达 4 倍。属既有隐患（`a9a61fd`, 2026-09-24），本轮电路改造**未覆盖该文件**。

**修复方向**：看板改为复用场景同一模型（`RL + RA`），与项目"单一可信源"原则一致。

### P2-4　规范与实现不一致：电表 `+/−` 接线柱

cheatsheet 铁律第 1 条写明"适用于所有页面"：电流表/电压表只有**正接线柱（标 `+`）/负接线柱（标 `−`）**，且必须"红进黑出"。但实测闭合电路等页面的 `A`/`V` 圆圈**没有任何 `+/−` 标记**；查 `DialMeter.tsx` 的 props 也**不支持**该能力（仅有 `type/x/y/r/value/variant/showLabel/labelPosition`）。

**建议**：要么把该铁律明确限定在"接线图/实物图/多用电表"（多用电表页的 `COM(−)`/`(+)` 已正确），要么给 `DialMeter` 增加 `terminals` 能力并在原理图页面统一开启。当前状态是"文档要求 > 组件能力"，属于规范空转。

### P2-5　下标 `_` 按字面显示（全局显示约定）

### P2-6　电感/线圈在原理图页面使用拟物金色线圈

`ACImpedanceScene`、`SelfInductionScene` 中，电阻用符号化空心框，而电感用 `Solenoid` 拟物金色线圈（含渐变与立体感）。同一张"原理图"内两种风格并存。cheatsheet 要求"所有电学实验原理图统一 `variant="symbolic"`"，建议确认此处是有意为之（场景化）还是遗漏。
